Hospital Radio - Voice Credits

The bundled Hospital Radio announcements were generated locally with Piper TTS.
The final mod contains pre-rendered audio only; Piper itself and the voice model
files are not distributed with the mod.

Piper TTS
---------
The announcements were rendered with Piper TTS.

Hospital Radio's local generation tool uses the maintained OHF-Voice Piper
implementation:
https://github.com/OHF-Voice/piper1-gpl

Piper software license: GPL-3.0-or-later.

Piper is a generation tool only and is not bundled with the Hospital Radio mod.
The Piper documentation states that it adds no additional restrictions to voice
models and that each voice model's MODEL_CARD should be reviewed for licensing.

Final packaged announcements
----------------------------
Final announcement assets use the naming convention:

HR_V001.ogg
HR_V002.ogg
...
HR_V100.ogg

The source TTS takes, Piper models and training datasets are not included in the
distributed mod.
