Where can I find my saves and logs?

BepInEx log

Inside your Project Hospital installation:

BepInEx\LogOutput.log

Project Hospital game log

Windows:

%USERPROFILE%\AppData\LocalLow\Oxymoron Games\Project Hospital\output_log.txt

Save games

Windows:

%USERPROFILE%\AppData\LocalLow\Oxymoron Games\Project Hospital\maps

Tip: copy one of the paths above into the Windows File Explorer address bar.

Linux / macOS

Linux game log:

~/.config/unity3d/Oxymoron Games/Project Hospital/Player.log

Linux saves:

~/.config/unity3d/Oxymoron Games/Project Hospital/maps

macOS game log:

~/Library/Logs/Unity/Player.log

macOS saves:

~/Library/Application Support/unity.Oxymoron Games.Project Hospital/maps
